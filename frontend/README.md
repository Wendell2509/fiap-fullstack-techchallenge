# Front-end Web - Tech Challenge (FIAP)

Interface Web desenvolvida em React com Vite para a plataforma educacional, integrada à API REST em Node.js.

## 🚀 Tecnologias Utilizadas

- **React**: Biblioteca principal para construção da interface.
- **Vite**: Ferramenta de build e servidor de desenvolvimento.
- **Axios**: Cliente HTTP para consumo dos endpoints da API.
- **CSS / Global Styles**: Estilização dos componentes e layouts.
